TERMINALES: ID STRING NUMBER = + ; , ( ) bold italic color upper lower section paragraph itemize item
NO_TERMINALES: Program StmtList Stmt DocStmt Expr ExprTail Term Factor FuncCall FunctionName Literal ItemList ItemTail
INICIAL: Program
PRODUCCIONES:
Program -> StmtList
StmtList -> Stmt ; StmtList | Stmt ; | Stmt
Stmt -> ID = Expr | DocStmt
DocStmt -> section ( Expr ) | paragraph ( Expr ) | itemize ( ItemList )
Expr -> Term ExprTail
ExprTail -> + Term ExprTail | ε
Term -> Factor
Factor -> FuncCall | Literal | ID | ( Expr )
FuncCall -> FunctionName ( Expr ) | color ( Expr , Expr )
FunctionName -> bold | italic | upper | lower
Literal -> STRING | NUMBER
ItemList -> item ( Expr ) ItemTail
ItemTail -> , item ( Expr ) ItemTail | ε
